# Đường dẫn tính từ GỐC MONOREPO. Kết thúc bằng "/" = cả thư mục; không có "/" = đúng file đó.
# Chỉ chủ repo (vai "owner") được sửa file này.
#
#   role <vai> <đường dẫn>...   Vùng RIÊNG của một vai (admin / staff): chỉ vai đó được sửa.
#   shared <đường dẫn>...       Dùng chung: vai nào cũng sửa được, nhưng chỉ THÊM, không đổi / xoá cái đã có.
#   addable <đường dẫn>...      Vùng khoá nhưng cho THÊM FILE MỚI; file đã có thì không được sửa.
#   lock <đường dẫn>...         Vùng khoá: file đã có không được sửa / xoá nếu thiếu nhãn "core-change" trên PR.
#
# Thứ tự ưu tiên khi một file khớp nhiều dòng: role > shared > addable > lock.
# Vai admin / staff mặc định KHÔNG được sửa bất cứ gì ngoài vùng của mình + shared + addable.
